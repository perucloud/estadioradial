Se utilizan los tres archivos JSON: 25 departamentos, 196 provincias y 1,892
distritos. En el portal los departamentos se presentan editorialmente como
regiones.

Los datos están versionados localmente. No se consulta GitHub mientras un
usuario crea o publica una noticia.
