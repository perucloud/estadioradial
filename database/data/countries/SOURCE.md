El portal utiliza **únicamente los nombres de países** de este archivo. Los
estados y ciudades del repositorio de origen no forman parte del sistema.

La copia se mantiene dentro del proyecto para que el panel y la publicación de
noticias no dependan de GitHub ni de una conexión a Internet. Las ubicaciones
que no estén en el catálogo pueden crearse manualmente desde el panel.

El repositorio de origen no publica una licencia en la revisión indicada. Antes
de redistribuir este catálogo como producto de datos independiente debe
confirmarse su licencia con el autor. Esta aplicación conserva la atribución y
la revisión exacta utilizadas.
